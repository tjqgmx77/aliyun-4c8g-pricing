## 经济型e、u2i、c9i差在哪：定位决定价格

- 网站平时负载不高、偶尔有峰值，e够用，一年省下大几百；
- 企业官网、几个中型应用混跑、想省心不折腾，u2i是这个价位最平衡的选择；
